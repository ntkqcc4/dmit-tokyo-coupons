## 六、Pro 和 T1 到底差在哪，怎么选

一句话区分：**Pro 买的是延迟，T1 买的是价格和流量。**

东京 Pro 到国内的延迟，按多个测评的实测大致在 50–90ms 区间，电信和联通方向偏低，晚高峰的表现是它主要的溢价理由。T1 没有这条线，跑国内访问延迟更高，高峰期波动也明显。

判断方法很简单，问自己一个问题：**访问这台机器的用户主要在哪里？**

- 用户在国内，且对速度有要求（网站、API、远程办公、需要低延迟的代理）→ 看 Pro
- 用户在日本或东南亚，或者只要求日本 IP、根本不在乎国内直连质量 → 看 T1
- 需要日本 IP 但预算压得很死 → 看 T1，但要接受国内访问体验一般

还有一个现实问题：**Pro 经常缺货。** 东京 Pro 的补货通常是"释放出一批可用 IP 资源"带来的小批量上架，官方客服对外也说过短期内不会大规模补货。T1 的库存状态同样会波动，有整理文章明确写过 T1 系列某段时间全部显示售罄。所以看到有货就基本等于看到机会，犹豫的代价可能是等下一轮。
